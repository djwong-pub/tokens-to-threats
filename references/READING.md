# Required reading: the verified corpus

132 papers, each verified against the arXiv API or the title page of the
PDF itself. **The PDFs are not in this package** -- they are third-party copyrighted.
Follow a link to read or download a paper from its own host; the book cites them by
these identifiers.

Format: title -- first author et al. (year published), venue, arXiv id where one
exists. Venue is stated where the source identifies it; the 7 non-arXiv entries come
from a named journal or proceedings site.

Regenerate this file with `make camera-ready` (it is written from
`required_reading_pdfs/manifest.csv`).
